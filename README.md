# DB600 固件界面改造项目

给夏日之音 DB600（解码 / 前级 / 耳放一体机）的 MCU 固件换上「A 主题」界面：黑底、琥珀色强调、无衬线字体。改动范围是主界面、设置菜单、语言选择界面和开机界面，只在 UI1 主题下生效；UI2 主题和所有音频控制逻辑保持原样。

- 做法：原固件没有源码，所以在原版 17-0 固件后面追加用 C 写的新代码，再把少数几个界面调用改成跳到新代码。完整过程见 [给AI的项目说明.md](给AI的项目说明.md)，整机界面逻辑见 [DB600界面逻辑说明-17-0.md](DB600界面逻辑说明-17-0.md)。
- 现成的固件在 Releases 里下载。**只适用于 17-0 旧屏版机器**。
- 效果截图在 `输出/模拟截图-第三步/` 和 `输出/模拟截图-第二步/`，是在电脑上用模拟器运行这份固件得到的画面。

## 文件夹
- `tools/`：工具
  - `arm-gnu-toolchain-14.2.rel1/`：Arm 官方 GNU 编译工具链，用来编译要注入固件的新代码
  - `python/`：unicorn（模拟器，测试注入的代码）、capstone（反汇编）。用法：`sys.path.insert(0, r'C:\Users\GLFTB\Desktop\DB600\tools\python')`
- `分析脚本/`：反汇编和补丁脚本
  - `ann.py`：带注释的反汇编，自动标出引脚、内存变量、函数名和跳转表。用法：`python -I ann.py <固件.bin> ins_170.pkl <起始地址> <结束地址>`
  - `gen_a170.py`：17-0 的 A 主题换皮补丁（只换图片和颜色）
  - `ins_170.pkl`：17-0 的反汇编缓存，`ins.pkl` 是 17-1 的
- `设计稿/`：画布设计稿的源文件（在线版：https://claude.ai/artifact/6TRnHL31NNTqb4L4sqAYHU）
- `DB600界面逻辑说明-17-0.md`：整台机器的界面逻辑（拨杆、按键、遥控、音量条、菜单、设置保存）
- `A主题补丁-17-0旧屏/`：只换图片和颜色的补丁副本
- `A主题补丁/`：基于 17-1 新屏的旧补丁，**不适合这台机器，不要刷**

- `A主题代码/`：A 主题代码补丁的源码。运行 `python -I build.py` 会生成字库和图片、编译、打补丁，输出到 `输出/`
  - `a_theme.c`：挂钩逻辑；`fw.h`：固件函数和变量地址；`mkassets.py`：新字库和新图片
  - 字体来自 `tools/fonts`（Barlow Condensed、Noto Sans SC，均为 OFL 开源授权）
- `输出/`：生成的补丁固件、`sym.txt`（新函数地址）和模拟截图
- `分析脚本/emu_ui.py`、`shot.py`、`test_*.py`：用模拟器跑固件界面并截图，用来在刷机前检查效果

## 原始固件（不改动）
- 桌面 `2026-10-24+夏日之音DB600 MCU程序17-0 旧屏 UI选择菜单2.bin`，SHA256 625118ca…e82d67

## 关键事实
- 程序起始地址 0x0800A000（前 40KB 是引导程序），芯片 Flash 512KB
- 设置存放在 Flash 0x0807F800，**新代码不能写到这里**
- 程序结束地址 0x0805B0AC，之后到 0x0807F800 之间大约 150KB 空闲
